What this page is

A demonstration, not yet an exercise: it has no quantitative target, because the metrics one would be set in — core flux, mean and peak flux density, leakage, ampere-turns, stored energy — have definitions in a two-dimensional slice that this lab has not yet verified. They are specified in docs/exercises/solenoid.md and will not be printed before they are checked.

The browser widgets have not been built. Run ./scripts/fetch-widgets.sh and reload the page.
